⚠️ When NOT to Use Lethe

Building trust through transparency about limitations

Single-file code analysis

Reason: Low-entropy/single-file code contexts

Better Alternative: Traditional grep/ripgrep

For simple single-file searches, lightweight text search tools are more efficient

Tiny contexts (< 100 tokens)

Reason: Contexts where Streaming alone suffices

Better Alternative: Direct LLM processing

Overhead of hybrid retrieval not justified for very small contexts

Exact string matching only

Reason: No semantic understanding needed

Better Alternative: Zoekt or ripgrep

Pure lexical tools excel at exact symbol/string matching

Budget-unconstrained scenarios

Reason: When token limits are not a concern

Better Alternative: Full context processing

Lethe's budget optimization provides no benefit when resources are unlimited
